# A way to attack a problem

Today is for practice, so here is a method that works for any small program. The three exercises (a discount calculator, a Caesar cipher and an RPG character) all follow it.

1. **Restate the problem** in your own words. What goes in, what comes out? Write two examples with the exact expected output.
2. **Break it down** into steps small enough to write in one or two lines each. Write them as comments first.
3. **Build the smallest piece** that works, run it, then add the next piece. Never write 40 lines before the first run.
4. **Print as you go.** When a result is wrong, `print` the values in between until you find the first step where reality differs from what you expected.
5. **Test the edges:** zero, one, the largest allowed value, empty input, invalid input.
6. **Tidy:** pick good names, remove the debugging prints, and put repeated code into a function.

# Finding things out yourself

You will not remember every function, and professionals do not either. Python can tell you:

```python
help(len)             # the built-in manual page for len
help(str.split)       # for a method
dir("")               # lists every method a string has
```

Also use the official docs (the _Library Reference_) and a search with the exact error message. Reading a docs page and trying one example in the shell takes two minutes and teaches more than copying an answer.

# Built-in functions worth knowing

`len(x)` (size), `min(...)`, `max(...)`, `sum(list)`, `abs(x)`, `round(x, 2)`, `sorted(list)`, `range(n)`, `int()`, `float()`, `str()`, `input()`, `print()`, `type()`. For text there are `ord("a")` (97, the code of a character) and `chr(97)` (the character), which the Caesar cipher needs:

```python
def shift(letter, key):
    if not letter.isalpha():
        return letter
    base = ord("A") if letter.isupper() else ord("a")
    return chr((ord(letter) - base + key) % 26 + base)    # % 26 wraps z back to a
```

# Importing a module

A **module** is a file of ready-made code. `import math` gives you `math.sqrt(16)` and `math.pi`; `import random` gives `random.randint(1, 6)`. Only the names you import are available, and `dir(math)` lists them. You will write your own modules later.

When you finish an exercise, ask: could another person run this and understand it? Add a docstring and a clear name or two, and you have made it so.
