# Bitcask design

A **log-structured hash table**: simple and fast.

```
data file (append-only):  [crc|ts|keysz|valsz|key|value] [crc|...] [crc|...] ...
keydir (RAM hash map):    key → {fileID, valuePos, valueSize}
```

| Op                     | How                                                                                          |
| ---------------------- | -------------------------------------------------------------------------------------------- |
| **Put**                | append a record to the active file, then point `keydir[key]` at it. **One sequential write** |
| **Get**                | `keydir` lookup → one `pread` at the offset                                                  |
| **Delete**             | append a **tombstone** record, remove from `keydir`                                          |
| **Startup**            | scan files (or hint files) to rebuild `keydir`                                               |
| **Compaction (merge)** | copy only the **live** records into a new file, update `keydir`, delete old files            |

Limits: **all keys must fit in RAM**; no range queries (hash index). Old values stay on disk until compaction (space amplification).

# Crash safety

Append-only means earlier records are never overwritten. If the process dies **mid-record**, the file ends with a **torn record**: wrong length or CRC. On recovery scan, stop at the first invalid record and **truncate** there; the write was never acknowledged, so dropping it is correct. To make an acknowledged write durable, call `f.flush()` and then `os.fsync(f.fileno())` (cost: latency; batch with group commit).

# Compaction vs concurrent reads

Readers hold `keydir` pointers into old files. Compaction must:

1. write a **new** file (never modify old ones),
2. update `keydir` entries **only if they still point to the old location** (a newer Put may have arrived),
3. delete old files only after no reader still uses them (reference count, or a lock around the swap).
   Otherwise a reader can get a stale offset, a deleted file, or a half-written record.

```python
import os, struct, threading, zlib
from dataclasses import dataclass

@dataclass
class Loc:
    off: int
    n: int

class Store:
    def __init__(self, fd: int, size: int = 0) -> None:
        self.fd, self.size = fd, size
        self.index: dict[bytes, Loc] = {}
        self.lock = threading.Lock()

    def put(self, k: bytes, v: bytes) -> None:
        body = struct.pack("<II", len(k), len(v)) + k + v
        rec = struct.pack("<I", zlib.crc32(body)) + body      # crc | klen | vlen | key | value
        with self.lock:
            off = self.size
            os.pwrite(self.fd, rec, off)                      # a real implementation loops on a short write
            self.size += len(rec)
            self.index[k] = Loc(off, len(rec))
```

# Record format

`crc32(4) | keyLen(4) | valLen(4) | key | value`. A tombstone uses `valLen = 0xFFFFFFFF` (or a flag byte). The CRC covers everything after itself.

# Steps

1. `open(dir)`: scan the data file from 0; for each record read header, verify length fits and CRC matches; update the index (delete on tombstone); on first bad record, `os.ftruncate(fd, last_good)`.
2. `put`, `get` (`os.pread`, verify CRC), `delete` (append tombstone).
3. `Compact()`: iterate the index, write live records to `data.new`, `os.fsync`, `os.replace` over the old file (atomic), rebuild the index. Protect with a lock.
4. CLI: `kv put k v`, `kv get k`, `kv del k`.

# Tests

- Put/Get/Delete round trip; overwrite returns the newest.
- **Reopen after write** returns all data.
- Truncate the file mid-record in a test, reopen: earlier records survive.
- Compact shrinks the file and keeps contents.
- Run a stress test with concurrent reader threads during compaction (lower `sys.setswitchinterval` to shake out interleavings) and check every read returns a value that was written.

# Expression notation

| Infix     | Postfix (RPN) | Prefix  |
| --------- | ------------- | ------- |
| `a+b*c`   | `abc*+`       | `+a*bc` |
| `(a+b)*c` | `ab+c*`       | `*+abc` |

**Infix → postfix (shunting-yard):** scan left to right:

- operand → output
- `(` → push
- `)` → pop to output until `(`
- operator → while the stack top is an operator with **higher or equal precedence** (for left-assoc), pop it to output; then push. (`^` is right-assoc: pop only when strictly higher.)
- end → pop everything.

```python
prec = {"+": 1, "-": 1, "*": 2, "/": 2, "^": 3}
out, st = [], []
for c in s:
    if c.isalnum():                              # operand
        out.append(c)
    elif c == "(":
        st.append(c)
    elif c == ")":
        while st[-1] != "(":
            out.append(st.pop())
        st.pop()
    else:
        while st and st[-1] != "(" and prec[st[-1]] >= prec[c]:
            out.append(st.pop())
        st.append(c)
while st:
    out.append(st.pop())
```

**Infix → prefix:** reverse the string, swap `(` and `)`, run infix→postfix with `>` instead of `>=` (so equal precedence isn't popped), reverse the result.

**Prefix → infix:** scan **right to left**; operand → push; operator → `a = pop(); b = pop(); push "(" + a + op + b + ")"`.

**Balanced brackets:** push openers; on a closer the top must be its match; stack empty at the end. O(n).

# Design for testability

Code is easy to test when it is easy to **control inputs** and **observe outputs**.

- **Inject** dependencies: a clock (`now: Callable[[], float] = time.time`), randomness, filesystem, network, instead of calling globals inside the logic.
- Take small **protocols** (or just plain callables) where you need substitutes; return concrete types.
- Keep **pure logic** (encode/decode, planning) separate from I/O so tests need no disk.
- Avoid module-level mutable state and import-time side effects.
- Use pytest's `tmp_path` fixture for files; fixtures with `yield` for teardown.
- **Doctests** double as docs:

```python
def get(self, k: bytes) -> bytes | None:
    """Return the value for k, or None.

    >>> s = Store.open_temp(); s.put(b"a", b"1"); s.get(b"a")
    b'1'
    """
```

Run them with `python3 -m doctest -v store.py` or `pytest --doctest-modules`.
