# Sorting

`sorted(items)` returns a new sorted list and `items.sort()` sorts in place. Both take two options:

```python
words = ["banana", "Apple", "fig", "cherry"]
sorted(words)                          # ['Apple', 'banana', 'cherry', 'fig']  capitals first
sorted(words, key=str.lower)           # ignore case
sorted(words, key=len)                 # by length: ['fig', 'Apple', 'banana', 'cherry']
sorted(words, reverse=True)            # descending
```

`key` is a **function** that is called on each item to produce what to sort by. Sorting by several fields works by returning a tuple: `key=lambda p: (p.city, p.name)`. A `lambda` is a one-line anonymous function: `lambda x: x * 2`. Python's sort is **stable**: items that compare equal keep their original order.

# Tuples

A **tuple** is like a list that cannot change: `point = (3, 4)`. Use it for a fixed group of values (coordinates, a name and an age). **Unpacking** assigns the pieces to names in one line:

```python
x, y = point
name, age = ("Ada", 36)
a, b = b, a                    # swap two variables
```

Because tuples are immutable (and hashable), they can be used as dictionary keys, and functions that "return several values" return a tuple. A one-item tuple needs a trailing comma: `(5,)`.

# List comprehensions

A comprehension builds a list from another in one line. These are the same:

```python
squares = []
for n in range(10):
    if n % 2 == 0:
        squares.append(n * n)

squares = [n * n for n in range(10) if n % 2 == 0]
```

The shape is `[expression for item in iterable if condition]`; the `if` is optional. Use a comprehension for a simple transform or filter, and a normal loop when the body needs more than one step. Related: `zip(a, b)` pairs items up, `[x for x in words if x.startswith("a")]` filters, and `{w: len(w) for w in words}` builds a dictionary (tomorrow).
