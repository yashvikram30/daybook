# Files

Programs forget everything when they stop. A **file** keeps data. Python reads and writes text files with `open`:

```python
with open("notes.txt", "a", encoding="utf-8") as f:     # "a" appends
    f.write("buy milk\n")

with open("notes.txt", encoding="utf-8") as f:           # default mode is "r" (read)
    for line in f:                                       # one line at a time
        print(line.rstrip("\n"))
```

- **Modes:** `"r"` read, `"w"` write (creates the file or **erases** it), `"a"` append, add `"b"` for bytes.
- **`with`** closes the file automatically, even if an error occurs. Use it every time.
- `f.read()` returns the whole file as one string, `f.readlines()` a list of lines, and looping over `f` gives lines lazily, which is best for big files.
- `write` does not add a newline for you; include `\n`.
- If the file may not exist, handle `FileNotFoundError` (more on that on day 3).
- Use `encoding="utf-8"` so the same program works on every computer.

A file path is relative to where you _run_ the program. `pathlib.Path("data") / "notes.txt"` builds paths safely on any operating system.

# Modules and the standard library

A **module** is a Python file you can reuse. Python ships with a large **standard library**:

```python
import math
from random import randint
import datetime as dt

math.sqrt(2)
randint(1, 6)
dt.date.today()
```

`import x` makes `x.name` available; `from x import name` brings just that name; `as` renames. Handy modules: `math`, `random`, `datetime`, `os` and `pathlib` (files and folders), `sys` (`sys.argv` is the list of command-line arguments), `json` (read and write structured data), `collections` (`Counter`, `defaultdict`), `csv`.

To use your own file, put `helpers.py` next to your script and write `import helpers`. The idiom `if __name__ == "__main__":` at the bottom of a file runs code only when the file is executed directly, not when it is imported.

# Third-party packages and pip

Anything not in the standard library comes from the Python Package Index (**PyPI**) and is installed with `pip install requests` (or `uv add requests`). Install into a **virtual environment** so each project keeps its own packages; you will set one up in week 4. Packages installed once in the wrong place are the most common reason for `ModuleNotFoundError`.

# Putting it together

Typical task: read a file, process each line, write a result.

```python
counts = {}
with open("book.txt", encoding="utf-8") as f:
    for line in f:
        for word in line.lower().split():
            counts[word] = counts.get(word, 0) + 1
for word, n in sorted(counts.items(), key=lambda kv: kv[1], reverse=True)[:5]:
    print(word, n)
```
