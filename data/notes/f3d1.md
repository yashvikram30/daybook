# Dictionaries: look things up by key

A **dictionary** (`dict`) maps **keys** to **values**: `ages = {"Ada": 36, "Lin": 29}`. Where a list finds items by position, a dictionary finds them by name, and does it quickly however large it grows.

```python
ages = {"Ada": 36, "Lin": 29}
ages["Ada"]                    # 36
ages["Sam"] = 41               # add or update
del ages["Lin"]                # remove
"Ada" in ages                  # True: `in` checks the keys
ages.get("Zed", 0)             # 0: a default instead of an error
ages["Zed"]                    # KeyError: the key is not there
```

Looping gives you three views:

```python
for name in ages:                      # keys
    print(name)

for age in ages.values():              # values
    print(age)

for name, age in ages.items():         # both, unpacked
    print(name, age)
```

Keys must be **immutable** (strings, numbers, tuples), values can be anything, including lists and other dictionaries. Since Python 3.7 a dictionary remembers the order you inserted keys in.

# The counting pattern

The most common dictionary job is counting how often something appears:

```python
counts = {}
for word in "the cat and the hat".split():
    counts[word] = counts.get(word, 0) + 1
print(counts)        # {'the': 2, 'cat': 1, 'and': 1, 'hat': 1}
```

Read it as: look up the current count (0 if new), add one, store it back. The same shape groups items: `groups.setdefault(key, []).append(item)`. A dictionary of dictionaries is a tidy way to hold records: `people["Ada"]["city"]`.

# Sets: unique items

A **set** holds each value at most once and has no order: `{1, 2, 3}`. An empty set is `set()`, because `{}` is an empty dictionary.

```python
a = {1, 2, 3, 4}
b = {3, 4, 5}
a & b          # {3, 4}        in both (intersection)
a | b          # {1, 2, 3, 4, 5}   in either (union)
a - b          # {1, 2}        in a but not b
a ^ b          # {1, 2, 5}     in exactly one
unique = set(["x", "y", "x"])  # removes duplicates
```

Checking `x in some_set` is fast, so if you test membership many times, convert a list to a set first. Sets are for questions like "which words appear in both texts?" and "how many distinct values are there?" (`len(set(items))`).

When choosing: **list** for an ordered sequence, **tuple** for a fixed record, **dict** for lookup by key, **set** for uniqueness and membership.
