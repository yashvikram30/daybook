# Why functions

A **function** is a named, reusable piece of code. You write it once and call it many times. It also lets you give a name to an idea (`letter_grade(score)`), test it on its own, and change it in one place.

```python
def letter_grade(score):
    """Return the letter for a score from 0 to 100."""
    if score >= 90:
        return "A"
    if score >= 80:
        return "B"
    return "C or below"

print(letter_grade(95))       # A
```

- `def name(parameters):` starts the definition; the indented block is the **body**.
- **Parameters** are the names inside the brackets; **arguments** are the actual values you pass in a call.
- `return` sends a value back to the caller and ends the function. A function with no `return` returns `None`.
- The string at the top is a **docstring**, a description of what the function does. Write one for every function.

# return is not print

`print` shows something to a human and gives nothing back. `return` hands a value to your code so it can be used further. A function that only prints cannot be tested or combined: `total = add(2, 3) * 2` works only if `add` returns the sum. A common beginner bug is `print(add(2, 3))` printing `None` because `add` printed instead of returning.

# Parameters in more detail

```python
def tip(total, percent=15, people=1):
    return total * percent / 100 / people

tip(80)                       # uses the defaults
tip(80, 20)                   # positional: matched by order
tip(80, people=4)             # keyword: matched by name
```

A **default value** is used when the caller leaves the argument out; parameters with defaults must come after those without. Use keyword arguments when a call would otherwise be hard to read. A function can return several values separated by commas, which Python packs into a **tuple**: `return low, high`, then `lo, hi = bounds(data)`.

# Scope

Variables made inside a function exist only while it runs: they are **local**. The outside world cannot see them, and two functions can use the same name without clashing.

```python
def double(x):
    result = x * 2
    return result

double(4)
print(result)        # NameError: result is not defined here
```

A function can read a variable defined outside it, but should not change it; pass values in as parameters and get results out through `return`. This keeps functions predictable, because the output depends only on the input.

# A way to build them

1. Say in one sentence what the function takes and gives back.
2. Write down two or three example calls with the answers you expect.
3. Write the body.
4. Call it with those examples and compare.

Small functions that each do one thing are easier to get right than one long block.
