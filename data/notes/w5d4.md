# How DNS resolves a name

```
app -> stub resolver (OS) -> recursive resolver (ISP / 8.8.8.8 / 1.1.1.1)
          cache miss:  -> root server    "who has .com?"        -> NS for .com
                       -> TLD (.com) server "who has example.com?" -> NS for example.com
                       -> authoritative server              -> A 93.184.x.x
```

The recursive resolver does the work (**iterative** queries to the hierarchy) and **caches** answers for each record's **TTL**.

**Caches sit at:** browser, OS stub resolver, router/ISP resolver, public resolver. **Lifetime is set by the zone owner** via TTL (they can't force a cache flush; lowering TTL before a change is standard).

# Record types

| Type     | Maps                               |
| -------- | ---------------------------------- |
| A / AAAA | name → IPv4 / IPv6                 |
| CNAME    | alias → canonical name             |
| NS       | zone → name servers                |
| MX       | domain → mail servers              |
| TXT      | arbitrary text (SPF, verification) |
| SOA      | zone metadata                      |

# Message format (RFC 1035)

12-byte header: `ID | flags | QDCOUNT | ANCOUNT | NSCOUNT | ARCOUNT` (each 16 bits, big-endian). Flags include QR (response), RD (recursion desired), TC (truncated), RCODE.

Names are **length-prefixed labels** ending in a zero byte: `3www7example3com0`. **Compression:** a 2-byte pointer `11xxxxxx xxxxxxxx` (top two bits set, 14-bit offset from message start) refers to an earlier name. Question = name + QTYPE (A=1) + QCLASS (IN=1).

# UDP vs TCP

UDP: connectionless datagrams, no handshake, no reliability or ordering, one packet in → one packet out. DNS uses UDP/53 for speed and low state (client retries on timeout). **Falls back to TCP** when the answer is truncated (`TC` bit; classic limit 512 bytes, larger with EDNS0), and for zone transfers (AXFR). Also encrypted variants: DoT, DoH.

```python
import socket

with socket.socket(socket.AF_INET, socket.SOCK_DGRAM) as sock:     # UDP
    sock.settimeout(2)
    sock.sendto(query, ("8.8.8.8", 53))
    data, addr = sock.recvfrom(1232)       # one datagram in, one datagram out
```

# Build a query

```python
import struct

header = struct.pack(">6H", 0x1234, 0x0100, 1, 0, 0, 0)       # id, flags (RD=1), 1 question, 0, 0, 0
qname = b"".join(bytes([len(l)]) + l.encode() for l in "example.com".split(".")) + b"\x00"
question = qname + struct.pack(">2H", 1, 1)                   # QTYPE=A, QCLASS=IN
query = header + question
```

Send via UDP to `8.8.8.8:53`; compare with `dig +norecurse example.com @8.8.8.8` and `dig +trace`. The `>` in the format means big-endian, which is network byte order.

# Parse

Read the header; skip/parse the question; for each answer: name (follow pointers: if the top two bits of a length byte are `11`, jump to the 14-bit offset; guard against pointer loops), TYPE, CLASS, TTL (u32), RDLENGTH, RDATA (4 bytes for A). `struct.unpack_from(">HHIH", data, offset)` reads the fixed part of a record at an offset without copying.

# Iterate

Start at a root server (e.g. `198.41.0.4`, a.root-servers.net) with RD=0; use the answer, or the NS names + glue A records in the _additional_ section, as the next server until you get an A answer.

# Greedy

Make the locally best choice at each step; it works when the problem has the **greedy-choice property** (a local optimum extends to a global one). Typical tools: **sort**, then a single pass; justify with an exchange argument.

```python
# Assign cookies: sort both; give the smallest sufficient cookie to the least greedy child
g.sort()
s.sort()
i = 0
for c in s:
    if i < len(g) and c >= g[i]:
        i += 1
return i
```

- **Lemonade change:** keep counts of `$5` and `$10`. For `$20` prefer `10+5` over `5+5+5` (fives are more useful).
- **Fractional knapsack:** sort items by `value/weight` descending; take whole items, then a fraction of the next.
- **Jump game I:** track the farthest reachable index; fail if `i > far`.

```python
far = 0
for i, v in enumerate(a):
    if i > far:
        return False
    far = max(far, i + v)
return True
```

- **Shortest job first:** sort burst times; average waiting time = mean of prefix sums.

Proof sketch habit: "if an optimal solution differs from greedy at step k, swap in the greedy choice and it's no worse."
