# File-like objects

Python programs plug together through "file-like" objects: anything with `read`/`write` methods. `sys.stdin`, files from `open`, sockets wrapped with `makefile`, `io.StringIO` and `io.BytesIO` buffers, and pipes from `subprocess` all behave the same way. **Dependency injection:** take the file as a parameter instead of using `sys.stdout`, so tests can pass a `StringIO`.

```python
import io, sys
from typing import TextIO

def greet(name: str, out: TextIO = sys.stdout) -> None:
    out.write(f"Hello, {name}")

buf = io.StringIO()
greet("Ada", buf)
assert buf.getvalue() == "Hello, Ada"
```

# `subprocess.Popen`

```python
import os, shutil, subprocess

proc = subprocess.Popen(
    ["grep", "-n", "foo"],
    stdin=subprocess.PIPE,            # or any open file, or None to inherit
    stdout=open("out.txt", "w"),      # any file with a real file descriptor (e.g. a file for `>`)
    cwd="/tmp",
    env={**os.environ, "A": "1"},
    text=True,
)
proc.communicate(input_text)          # write stdin, wait, collect
print(proc.returncode)                # negative means "killed by signal N"
path = shutil.which("ls")             # search $PATH
```

`subprocess.run(args, check=True)` raises `CalledProcessError` for a non-zero exit. Pass a **list** of arguments, not a string with `shell=True`: the list never goes through a shell, so spaces and quotes in values cannot be misread (or injected).

# Builtins: why `cd` must be one

`chdir` changes the working directory of the **calling process**. If a child did it, only the child would change. The shell must call `os.chdir` itself. Same for `exit`, `export`.

# Redirection under the hood

```python
fd = os.open("out.txt", os.O_WRONLY | os.O_CREAT | os.O_TRUNC, 0o644)
os.dup2(fd, 1)    # fd 1 (stdout) now refers to out.txt; the old fd 1 is closed first
os.close(fd)      # done in the child, between fork and exec
os.execvp(argv[0], argv)
```

Python's `stdout=file` argument to `subprocess` makes the forked child perform the `dup2`s for you before `exec`. You can also do it by hand: `os.dup2(fd, 1)` in a child made with `os.fork`.

| exec variant      | Meaning               |
| ----------------- | --------------------- |
| `execl/execv`     | list / vector of args |
| `...p` (`execvp`) | search `$PATH`        |
| `...e` (`execve`) | explicit environment  |

# Skeleton

```python
import os, sys

def main() -> None:
    while True:
        try:
            line = input("wish> ")
        except EOFError:
            break
        try:
            args = tokenize(line)               # handle "quoted strings" and \ escapes
        except ValueError as e:
            print(e, file=sys.stderr)
            continue
        if not args:
            continue
        match args[0]:
            case "exit":
                sys.exit(0)
            case "cd":
                try:
                    os.chdir(args[1])
                except (IndexError, OSError) as e:
                    print(e, file=sys.stderr)
            case "pwd":
                print(os.getcwd())
            case _:
                run(args)
```

- Redirect: split tokens at `>`; `f = open(name, "w")`; `Popen(args, stdout=f)`; close after `wait`.
- Report errors to stderr; keep the loop alive after a failure (catch `FileNotFoundError` when the command does not exist).
- Validate against the OSTEP processes-shell tests (they use `wish` as the name).
- By hand: in a forked child, `os.open` + `os.dup2(fd, 1)` before `os.execvp`, and compare it with `stdout=`.

# Merge-sort-based counting

**Count inversions** (`i<j`, `a[i]>a[j]`): during merge, when taking an element from the **right** half, it is smaller than all remaining left elements, so `count += len(left) - i`. O(n log n).

```python
def sort_count(a: list[int]) -> tuple[list[int], int]:
    if len(a) <= 1:
        return a, 0
    m = len(a) // 2
    l, cl = sort_count(a[:m])
    r, cr = sort_count(a[m:])
    cnt, out = cl + cr, []
    i = j = 0
    while i < len(l) and j < len(r):
        if l[i] <= r[j]:
            out.append(l[i])
            i += 1
        else:
            out.append(r[j])
            j += 1
            cnt += len(l) - i
    out += l[i:] + r[j:]
    return out, cnt
```

**Reverse pairs** (`a[i] > 2*a[j]`): same recursion, but count pairs with a separate two-pointer pass over the two sorted halves **before** merging. In Java or C++ use a 64-bit type for `2*x`; Python ints cannot overflow.

**Max product subarray:** keep both the max and min product ending here (a negative flips them).

```python
mx = mn = best = a[0]
for v in a[1:]:
    if v < 0:
        mx, mn = mn, mx
    mx, mn = max(v, mx * v), min(v, mn * v)
    best = max(best, mx)
```

**Merge two sorted arrays in place:** gap method (Shell-sort style) with gap = ⌈(n+m)/2⌉ halving until 1, swapping out-of-order pairs; or swap `a[i]` with `b[0]` then re-sort `b` by insertion.

# Lint your shell scripts

Shell has sharp edges (word splitting, unset variables, silent failures). **ShellCheck** finds them.

```bash
#!/usr/bin/env bash
set -euo pipefail          # exit on error, on unset var, and on pipe failures
f="$1"
cp -- "$f" "$f.bak"        # quote variables: "$f" not $f
```

Typical findings: unquoted `$var` (SC2086), `cd` without `|| exit`, `[ $x == y ]` portability, useless `cat`. Run `shellcheck script.sh` locally or in CI; fix or justify with a `# shellcheck disable=SCxxxx` comment.

1. **`cd` builtin.** Working directory is per-process state. A child process that runs `chdir` changes only itself and exits; the shell would be unaffected. So the shell must call `chdir` in its own process.
2. **dup2.** Before: fd 1 → terminal, fd 3 → out.txt. `dup2(3, 1)`: fd 1 is closed and now points to the same open file description as fd 3 (both → out.txt); then `close(3)`. Anything the program writes to fd 1 lands in the file. Passing `stdout=f` to `subprocess.Popen` makes it do the same fork-time fd arrangement (it passes `f` as the child's fd 1).
