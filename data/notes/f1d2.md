# Variables: names for values

A **variable** is a name that refers to a value. You create one by assigning with `=`:

```python
age = 30
name = "Ada"
price = 4.5
print(name, "is", age)
```

Read `=` as "make this name refer to that value", not as the equals of mathematics. You can reassign: `age = age + 1` takes the current value of `age`, adds one, and makes the name refer to the result. Names use letters, digits and underscores, cannot start with a digit, and are case-sensitive. The convention is `snake_case` (`total_price`). Pick names that say what the value means.

# Types

Every value has a **type**, which decides what you can do with it. The ones you need first:

| Type       | Example         | Used for                                     |
| ---------- | --------------- | -------------------------------------------- |
| `int`      | `42`, `-7`      | whole numbers                                |
| `float`    | `3.14`, `2.0`   | numbers with a fractional part (approximate) |
| `str`      | `"hello"`       | text                                         |
| `bool`     | `True`, `False` | yes or no                                    |
| `NoneType` | `None`          | "no value"                                   |

`type(x)` tells you the type of `x`. Mixing types can fail: `"3" + 4` raises a **TypeError**, because Python will not guess whether you meant text or a number. Convert deliberately with `int("3")`, `float("2.5")` and `str(4)`.

# Arithmetic

| Operator | Meaning                      | Example             |
| -------- | ---------------------------- | ------------------- |
| `+ - *`  | add, subtract, multiply      | `2 * 3` is `6`      |
| `/`      | divide, always gives a float | `7 / 2` is `3.5`    |
| `//`     | floor division (round down)  | `7 // 2` is `3`     |
| `%`      | remainder                    | `7 % 2` is `1`      |
| `**`     | power                        | `2 ** 10` is `1024` |

Multiplication and division happen before addition and subtraction; use brackets to be clear. `x += 1` is shorthand for `x = x + 1` (and `-=`, `*=` work the same way). Floats are stored approximately, so `0.1 + 0.2` shows `0.30000000000000004`. That is normal, so never test floats for exact equality.

# Input

`input("prompt")` pauses, waits for the user to type a line, and returns it **as text**, always. To do arithmetic on it, convert:

```python
bill = float(input("Bill amount: "))
tip = bill * 0.15
print(f"Tip: {tip:.2f}")      # an f-string: {...} inserts a value; :.2f means 2 decimal places
```

If the user types something that is not a number, `float()` raises a `ValueError`; you will learn to handle that in week 3. For now, notice that most "my arithmetic is wrong" bugs are really "I forgot that `input()` gives text".

A good habit: before you run a line, say aloud what you expect it to print. Being surprised is how you find the gaps in your understanding.
