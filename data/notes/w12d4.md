# PyTorch in one screen

- **Tensor:** an n-d array like NumPy's, plus **autograd** (set `requires_grad=True`) and GPU support.
- `loss.backward()` fills `.grad` for every parameter via the same chain rule you coded by hand; **optimizers** (`SGD`, `Adam`) apply updates.
- `nn.Module` bundles parameters + `forward`.

```python
import torch, torch.nn as nn
from torch.utils.data import DataLoader
from torchvision import datasets, transforms

torch.manual_seed(0)
tf = transforms.Compose([transforms.ToTensor(), transforms.Normalize((0.1307,), (0.3081,))])
train = DataLoader(datasets.MNIST("data", train=True, download=True, transform=tf), batch_size=64, shuffle=True)
model = nn.Sequential(nn.Flatten(), nn.Linear(784, 128), nn.ReLU(), nn.Linear(128, 10))
loss_fn = nn.CrossEntropyLoss()                    # takes raw LOGITS (applies log-softmax itself)
opt = torch.optim.Adam(model.parameters(), lr=1e-3)

for epoch in range(3):
    model.train()
    for xb, yb in train:
        opt.zero_grad()
        loss = loss_fn(model(xb), yb)
        loss.backward()
        opt.step()
```

Evaluation: `model.eval()` and `with torch.no_grad():` (disables dropout/batchnorm training behavior and gradient tracking).

# Karpathy's recipe (avoid silent bugs)

1. **Become one with the data** (look at samples, label balance, outliers).
2. Build an **end-to-end skeleton** with a dumb baseline; fix seeds; test the pipeline.
3. **Overfit a tiny batch** (e.g. 5-10 examples) to ~0 loss. If you can't, there's a bug (labels, loss, shapes, learning rate, data pipeline).
4. Then regularize, tune, and scale; change **one thing at a time**; check the initial loss (`≈ ln(10) ≈ 2.30` for 10 balanced classes).

# Reproducibility

Seed `random`, `numpy`, `torch` (`torch.manual_seed`), a seeded `generator` for the DataLoader, `torch.use_deterministic_algorithms(True)`; note GPU kernels and some ops are nondeterministic; same hardware/library versions needed for bitwise equality. Expect ~97-98% test accuracy for this MLP after a few epochs.

# What PyTorch does for you vs your micrograd

Automatic differentiation of arbitrary tensor graphs, **vectorized** batched ops (BLAS/GPU), built-in layers/losses/optimizers, data loading, device management. The mathematics is the same chain rule.

# Shortest paths with other constraints

**Shortest path in a binary grid (BFS):** nodes = open cells; unit edges; BFS by levels (4 or 8 directions depending on the problem). Return `-1` if unreachable.

**Path with minimum effort** (effort = max absolute height difference along the path): Dijkstra where the distance of a path is the **max edge** (relax with `max(cur, |h[u]-h[v]|)`); or binary search the effort + BFS feasibility.

**Cheapest flights within K stops:** `K+1` edges at most. **BFS by levels / Bellman-Ford** with a copy of `dist` per round (so a round uses only last round's values), or Dijkstra with state `(node, stops)`.

```python
INF = float("inf")
dist = [INF] * n
dist[src] = 0
for _ in range(k + 1):
    nxt = dist.copy()
    for frm, to, price in flights:
        if dist[frm] < INF:
            nxt[to] = min(nxt[to], dist[frm] + price)
    dist = nxt
```

**Minimum multiplications to reach end:** states are values modulo M (e.g. 100000); BFS from `start` applying each multiplier, `(cur*m) % M`; answer = level when `end` is reached.

| Weights                        | Algorithm              |
| ------------------------------ | ---------------------- |
| unit                           | BFS                    |
| non-negative                   | Dijkstra               |
| negative edges (no neg cycles) | Bellman-Ford O(VE)     |
| DAG                            | topological relaxation |

# Experiment tracking

You will run dozens of experiments; without records you can't tell which change helped.

**Log for every run:** unique run id, **config/hyperparameters**, **random seed**, **code version** (git commit, dirty flag), **data version** (hash/path), library versions, **metrics over time**, final metrics, and artifacts (model file, plots).

Tools: **MLflow**, **Weights & Biases**, **TensorBoard**, or at minimum a `runs/` folder with a `config.json` + `metrics.csv` per run.

```python
run = Path("runs") / time.strftime("%Y%m%d-%H%M%S"); run.mkdir(parents=True)
(run / "config.json").write_text(json.dumps({**cfg, "seed": seed, "git": git_hash()}))
```

Habits: change **one thing** per experiment; compare with the same seed/splits; report variance across seeds; keep a running log of what you learned.
