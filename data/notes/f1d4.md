# Booleans and comparisons

A **boolean** is `True` or `False`. Comparisons produce them:

| Operator             | Meaning                       |
| -------------------- | ----------------------------- |
| `==`, `!=`           | equal, not equal              |
| `<`, `<=`, `>`, `>=` | ordering                      |
| `in`, `not in`       | is it inside a string or list |

Note `==` (compare) is different from `=` (assign); mixing them up is a classic first bug. Python allows chained comparisons: `0 <= score <= 100`.

Combine booleans with `and`, `or` and `not`:

```python
age = 20
has_ticket = True
print(age >= 18 and has_ticket)       # True
print(not has_ticket)                 # False
```

`and` is true only if both sides are; `or` is true if at least one is. Python stops as soon as the answer is known (**short-circuit**), so `x != 0 and 10 / x > 2` never divides by zero.

**Truthiness:** in an `if`, `0`, `""` (empty string), `[]` and `None` count as false and nearly everything else as true, so `if name:` means "if name is not empty".

# if, elif, else

```python
score = int(input("Score 0-100: "))

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "F"
print("Grade:", grade)
```

Rules to remember:

- The line ends with a **colon**, and the block under it is **indented** (four spaces). Indentation _is_ the structure in Python; mixing tabs and spaces causes an `IndentationError`.
- Python checks the conditions **top to bottom and runs only the first that is true**. That is why the order above works: a score of 95 is also `>= 80`, but the first test already caught it. Put the most specific test first.
- `elif` and `else` are optional. With no `else`, nothing happens when no condition matches.
- You can nest an `if` inside another block, but flatter is easier to read.

A short form for a simple choice: `label = "adult" if age >= 18 else "minor"`.

# Testing your logic

Decisions are where bugs hide, at the **edges**. For the grade program, try exactly 90, exactly 89, 0, 100 and a value like -5 or 150 that should be rejected. Write the expected answer down first, then run. When the output differs, either the code or your expectation was wrong, and finding out which is the lesson.

Remember that `input()` returns text. `"85" >= 80` is a `TypeError`, so convert with `int(...)` before comparing.
