# A neural network

A **neuron** computes `a = f(w·x + b)`. A **layer** is many neurons: `a = f(Wx + b)`. A network stacks layers. The activation `f` must be **nonlinear** (ReLU `max(0,z)`, tanh, sigmoid); without it the stack collapses to a single linear map.

```
x ──► [W1,b1]──ReLU──► [W2,b2]──ReLU──► [W3,b3] ──► ŷ ──► loss(ŷ, y)
```

Training: **forward pass** (compute the loss) → **backward pass** (gradients of the loss w.r.t. every parameter) → **update** (`p -= lr * grad`).

# Backpropagation

The computation is a **graph** of simple operations. The **chain rule** says the gradient of the output w.r.t. an input is the product of local derivatives along the path (summed over all paths). Backprop applies it **once, in reverse topological order**, reusing intermediate gradients, so the cost is about one extra forward pass, not one per parameter.

Local rules: for `c = a·b`: `∂c/∂a = b`, `∂c/∂b = a`; for `c = a+b`: both 1; `tanh`: `1−t²`; `ReLU`: `1 if z>0 else 0`.

# micrograd in 25 lines (core idea)

```python
class Value:
    def __init__(self, data, children=()):
        self.data, self.grad, self._prev, self._backward = data, 0.0, set(children), lambda: None
    def __add__(self, o):
        o = o if isinstance(o, Value) else Value(o); out = Value(self.data + o.data, (self, o))
        def _b(): self.grad += out.grad; o.grad += out.grad
        out._backward = _b; return out
    def __mul__(self, o):
        o = o if isinstance(o, Value) else Value(o); out = Value(self.data * o.data, (self, o))
        def _b(): self.grad += o.data * out.grad; o.grad += self.data * out.grad
        out._backward = _b; return out
    def backward(self):
        topo, seen = [], set()
        def build(v):
            if v not in seen: seen.add(v); [build(c) for c in v._prev]; topo.append(v)
        build(self); self.grad = 1.0
        for v in reversed(topo): v._backward()
```

Note `+=`: a value used in several places receives gradient from **each** use.

**Zero the gradients each step** because gradients **accumulate** (`+=`); otherwise last step's gradient adds to this one's.

# Gradient checking

Compare the analytic gradient with a **finite difference** `(f(x+h) − f(x−h)) / 2h`, `h ≈ 1e-5`; relative error should be ≲ 1e-6 (float64). It catches nearly all backprop bugs; use it only for testing (slow).

# Weighted and word graphs

**Word ladder (shortest transformation length):** BFS where nodes are words, edges connect words differing by one letter. To find neighbors quickly, bucket words by **wildcard patterns** (`h*t` → hot, hit, hat). Levels = answer. **Word ladder II** (all shortest sequences): BFS to record each word's level (and parents), then DFS/backtrack along parents.

**Dijkstra** (non-negative weights): always expand the closest unsettled node using a **min-heap**. `O((V+E) log V)`.

```python
import heapq

INF = float("inf")
dist = [INF] * n
dist[src] = 0
parent = [-1] * n
pq = [(0, src)]                                      # (distance, node); heapq is a min-heap
while pq:
    d, u = heapq.heappop(pq)
    if d > dist[u]:
        continue                                      # stale entry
    for v, w in adj[u]:
        nd = d + w
        if nd < dist[v]:
            dist[v] = nd
            parent[v] = u
            heapq.heappush(pq, (nd, v))
```

**Print the path:** follow `parent[]` from the target back to the source and reverse.

**Fails with negative edges** (use Bellman-Ford). Unweighted → BFS is enough.

# Test numerical code

Floating point breaks naive equality.

- **Tolerances:** `np.testing.assert_allclose(a, b, rtol=1e-6, atol=1e-8)`, `pytest.approx`, `math.isclose`. Never `==` on floats.
- **Gradient checks** for any hand-written backward pass.
- **Known answers:** tiny inputs you can compute by hand; compare with a trusted library (NumPy, PyTorch).
- **Invariants:** softmax sums to 1, probabilities in [0,1], loss ≥ 0, loss decreases on a tiny dataset, shapes preserved, permutation-invariance where expected.
- **Edge cases:** zeros, huge/tiny values (use `log-sum-exp`, subtract the max before `exp`), NaN/inf propagation, empty batches.
- **Seeds** fixed; tests run fast.
- Property-based testing (Hypothesis) for algebraic laws.

```python
def test_softmax_stable():
    p = softmax(np.array([1000., 1001.]))     # naive exp would overflow
    assert np.isfinite(p).all() and np.isclose(p.sum(), 1.0)
```
