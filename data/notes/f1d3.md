# Strings are sequences of characters

A **string** is text in quotes: `'hi'` or `"hi"` (the same). Use the other kind of quote inside: `"it's fine"`. A backslash starts an **escape**: `"\n"` is a new line, `"\t"` a tab, `"\\"` a backslash. Triple quotes hold text across several lines.

Strings are **immutable**: you can never change one in place, only make a new one. `s.upper()` returns a new string and leaves `s` alone, so remember to keep the result: `s = s.upper()`.

# Indexing and slicing

Each character has a position, counting from **0**. Negative positions count from the end.

```python
s = "python"
s[0]        # 'p'
s[-1]       # 'n'
s[1:4]      # 'yth'   from index 1 up to, but not including, 4
s[:2]       # 'py'
s[2:]       # 'thon'
s[::-1]     # 'nohtyp' a step of -1 reverses
len(s)      # 6
```

`s[10]` is an **IndexError**, but a slice such as `s[10:]` just gives an empty string. The "up to but not including" rule means `s[a:b]` has `b - a` characters, and `s[:n] + s[n:]` is always the whole string.

# Operations and methods

- Join with `+` and repeat with `*`: `"ab" + "cd"` is `"abcd"`, `"ab" * 3` is `"ababab"`. Text and numbers do not mix without `str()`.
- Test membership with `in`: `"th" in s` is `True`.
- Methods are functions attached to a value, called with a dot:

| Method                                   | Does                                    |
| ---------------------------------------- | --------------------------------------- |
| `s.lower()`, `s.upper()`                 | change case                             |
| `s.strip()`                              | remove spaces from both ends            |
| `s.replace("a", "b")`                    | replace every occurrence                |
| `s.split(",")`                           | split into a list of pieces             |
| `",".join(parts)`                        | join a list of strings with a separator |
| `s.find("x")`                            | index of the first match, or `-1`       |
| `s.startswith("ab")`, `s.endswith("ab")` | test the ends                           |
| `s.isdigit()`                            | are all characters digits               |

# f-strings

An **f-string** puts values inside text: put `f` before the quote and expressions in `{}`.

```python
name, score = "Ada", 91.456
print(f"{name} scored {score:.1f}%")      # Ada scored 91.5%
print(f"{name!r:>10}")                      # formatting options after a colon
```

It is clearer and less error-prone than gluing pieces with `+`. When a program needs to clean up what a user typed, the usual chain is `text.strip().lower()`.

A word on comparison: `"apple" < "banana"` compares letter by letter (alphabetical, with capitals before lowercase), and `"10" < "9"` is `True` because it compares characters, not numbers.
