# CI with GitHub Actions

A **workflow** (YAML in `.github/workflows/`) runs **jobs** (on runners) made of **steps**, triggered by **events**.

```yaml
name: ci
on: { push: { branches: [main] }, pull_request: {} }
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: astral-sh/setup-uv@v5
        with: { enable-cache: true }
      - run: uv sync --frozen
      - run: uv run ruff check . && uv run ruff format --check .
      - run: uv run mypy src
      - run: uv run pytest -q # also runs the saved Hypothesis examples
```

Add a build step (`uv build`) and a matrix over Python versions. Require the checks on `main` (**branch protection**).

# Docker multi-stage build

Install dependencies in a build stage; ship only the finished virtual environment and your code.

```dockerfile
FROM python:3.13-slim AS build
COPY --from=ghcr.io/astral-sh/uv:latest /uv /usr/local/bin/uv
ENV UV_PYTHON_DOWNLOADS=never UV_COMPILE_BYTECODE=1
WORKDIR /app
COPY pyproject.toml uv.lock ./
RUN uv sync --frozen --no-dev --no-install-project      # dependencies first, so this layer caches
COPY src ./src
RUN uv sync --frozen --no-dev

FROM python:3.13-slim
RUN useradd --create-home app
WORKDIR /app
COPY --from=build /app /app
ENV PATH="/app/.venv/bin:$PATH" PYTHONUNBUFFERED=1
USER app
ENTRYPOINT ["python", "-m", "kvservice"]
```

A slim base, locked dependencies and a non-root user give a small, reproducible image (around 150-200 MB, depending on your dependencies; compiled packages such as NumPy make it larger). Pin the base image by digest for fully reproducible builds.

# Observability: logs, metrics, traces

- **Metrics** (cheap, aggregate): the **four golden signals**: latency, traffic, errors, saturation. Prometheus: counters, gauges, **histograms** for latency (alert on p99).

```python
from prometheus_client import Counter, Histogram, make_asgi_app

REQS = Counter("http_requests_total", "Requests", ["path", "code"])
DUR = Histogram("http_request_seconds", "Request latency", ["path"])
app.mount("/metrics", make_asgi_app())               # exposes /metrics for Prometheus to scrape
```

- **Logs:** structured (the `logging` module with a JSON formatter) with request ids. **Traces:** one request across services (OpenTelemetry).
- **Profiling a live service:** `py-spy dump --pid <pid>` shows every thread's stack, and `py-spy record` makes a flame graph; run them from the host or a sidecar, and never expose a profiling endpoint publicly.

# Checklist

1. **CI:** `.github/workflows/ci.yml` as above (ruff, mypy, pytest); confirm a failing test turns the badge red. Add the badge to the README.
2. **Dockerfile** (multi-stage, locked dependencies with uv, non-root); `docker build -t kv . && docker images kv` (target < 200 MB); `docker run -p 8080:8080 kv`.
3. **Metrics:** middleware recording `http_requests_total{path,code}` and a latency histogram; `curl localhost:8080/metrics`. Use **route templates**, not raw URLs, as labels (unbounded labels explode memory).
4. **Logs:** JSON from the `logging` module with `req_id`, method, path, status, duration.
5. **Profiling:** make sure `py-spy` can attach (it needs `SYS_PTRACE` in a container) and keep any debug endpoint on `127.0.0.1` only.
6. **Runbook** (`docs/runbook.md`): how you know it's unhealthy (alerts on error rate, p99, saturation), first three checks (recent deploy? dependency health? resource saturation?), mitigations (rollback, restart, scale), who to escalate to.

# Multi-source BFS and grids

**Multi-source BFS:** push **all sources** into the queue at distance 0 and expand level by level; each cell gets its distance to the **nearest** source in one O(R·C) pass.

```python
from collections import deque

# Rotting oranges / 01-matrix style
q = deque((r, c) for r in range(m) for c in range(n) if g[r][c] == 2)
minutes = 0
while q:
    rotted = False
    for _ in range(len(q)):                    # one level = one minute
        r0, c0 = q.popleft()
        for dr, dc in DIRS:
            r, c = r0 + dr, c0 + dc
            if 0 <= r < m and 0 <= c < n and g[r][c] == 1:
                g[r][c] = 2
                q.append((r, c))
                rotted = True
    if rotted:
        minutes += 1
```

After the loop, any remaining `1` → impossible (`-1`).

| Problem                                 | Trick                                                                                                                           |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Rotting oranges                         | sources = rotten; answer = number of levels                                                                                     |
| 01 matrix (nearest 0)                   | sources = all 0s; set `dist` of 1s when reached                                                                                 |
| Number of enclaves / surrounded regions | BFS/DFS from **boundary** cells to mark what _can_ escape; count/flip the rest                                                  |
| Distinct islands                        | record each island's **shape** as relative coordinates (or DFS path string) from its first cell; count unique shapes with a set |

```python
sig.append((r - r0, c - c0))        # normalized cell; store tuple(sig) in a set of shapes
```

# Pipeline as code

Build, test and deploy steps live **in the repository**, versioned and reviewed like code.

- **Reproducible:** pinned toolchain versions, locked dependencies (`uv.lock`), containerized builds; same result on any machine.
- **Fast feedback:** run cheap checks first (format, lint, type check, unit), then slower ones; cache dependencies; parallelize.
- **Gates:** required checks and reviews on `main`; no direct pushes; secrets via CI secret store, not the repo.
- **Safe delivery:** deploy **small, frequent** changes; **canary / staged rollout**, **feature flags**, one-click **rollback**; automate it.
- **Trunk-based** development: short-lived branches.
- Keep the pipeline itself tested (change it in a PR, watch it run).
