# Lists

A **list** holds an ordered collection, written in square brackets: `scores = [90, 75, 82]`. It can mix types, grow and shrink, and be changed in place (it is **mutable**, unlike a string).

```python
fruits = ["apple", "banana"]
fruits.append("cherry")        # add at the end
fruits.insert(0, "kiwi")       # add at a position
fruits.remove("banana")        # remove the first matching value
last = fruits.pop()            # remove and return the last
len(fruits)                    # how many
"apple" in fruits              # True
fruits[0]                      # first; indexing and slicing work as for strings
```

Useful: `sum(nums)`, `min(nums)`, `max(nums)`, `sorted(nums)` (returns a new sorted list) and `nums.sort()` (sorts in place and returns `None`; a classic trap is writing `nums = nums.sort()`).

**Two names, one list.** `b = a` does not copy; both names refer to the same list, so a change through one shows through the other. Make a copy with `b = a[:]` or `a.copy()`.

# Loops

A `for` loop does something once for each item:

```python
for fruit in fruits:
    print(fruit.upper())

for i in range(5):             # 0, 1, 2, 3, 4
    print(i)

for i, fruit in enumerate(fruits):     # position and item together
    print(i, fruit)
```

`range(stop)`, `range(start, stop)` and `range(start, stop, step)` stop **before** `stop`. A `while` loop repeats as long as a condition is true; make sure something inside changes it, or it never ends (press Ctrl-C to stop a runaway loop).

```python
n = 10
while n > 0:
    print(n)
    n -= 1
```

Inside a loop, `break` leaves it and `continue` skips to the next pass.

# Patterns you will use constantly

**Accumulate:** start with a neutral value and update it.

```python
total = 0
for x in nums:
    total += x
average = total / len(nums)
```

**Find the biggest:** `best = nums[0]`, then `if x > best: best = x`. **Filter:** build a new list with `result.append(x)` inside an `if`. **Count:** `count += 1` when a condition holds.

Do not add or remove items from a list while looping over it; build a new list instead, or you will skip items. And remember loops are not just for numbers: `for ch in "hello"` visits each character, which is how you count vowels or check a PIN.

Nested loops multiply: a loop inside a loop runs the inner block `outer × inner` times, which is how you print a grid or compare every pair.
