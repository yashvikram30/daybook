# Physical clocks are unreliable

- Two kinds: **time-of-day** (wall clock, can jump when NTP corrects, leap seconds) and **monotonic** (only goes forward; use it for **durations/timeouts**, but its value is meaningless across machines).
- Clocks **drift** (≈ 10-100 ppm) and are synchronized only to ms-ish accuracy by NTP (µs-ms with PTP/GPS; Google TrueTime gives an uncertainty interval).
- So you **cannot order events across machines by timestamp**: skew can make a later event on B look earlier than an earlier event on A. Last-write-wins by timestamp can silently drop a newer write.

# Happens-before (Lamport)

`a → b` if: (1) same process, `a` before `b`; or (2) `a` = send(m) and `b` = receive(m); or (3) transitively. If neither `a → b` nor `b → a`, they are **concurrent** (no causal path, _not_ "at the same time").

# Lamport clock

```
local event or send:  L = L + 1   (send carries L)
receive(m):           L = max(L, m.L) + 1
```

Guarantee: `a → b ⇒ L(a) < L(b)`. **Not** the converse: `L(a) < L(b)` doesn't mean `a` caused `b`. Gives a total order (tie-break by node id) consistent with causality.

# Vector clock

One counter per node: `V[0..n-1]`.

```
local event:   V[i]++
send:          V[i]++; attach V
receive(m):    V = elementwise max(V, m.V); V[i]++
```

Compare: `V1 ≤ V2` iff every entry ≤. `a → b ⇔ V(a) < V(b)` (≤ and ≠). If neither dominates → **concurrent**. So vector clocks can **detect concurrency** (conflicts) and exactly characterize causality; Lamport clocks cannot. Cost: O(n) space per timestamp.

```python
def less(a: list[int], b: list[int]) -> bool:          # a happened before b
    return all(x <= y for x, y in zip(a, b)) and a != b

def concurrent(a: list[int], b: list[int]) -> bool:
    return not less(a, b) and not less(b, a) and a != b
```

Used by Dynamo-style stores to find conflicting writes (version vectors). **Hybrid logical clocks** combine physical time with a logical counter.

```python
class Lamport:
    def __init__(self) -> None:
        self.t = 0

    def tick(self) -> int:
        self.t += 1
        return self.t

    def recv(self, m: int) -> int:
        self.t = max(self.t, m) + 1
        return self.t
```

# Concurrent writes

Two clients write key `x` at different nodes without seeing each other: their vectors are incomparable → report a **conflict** (keep both siblings), vs a causally later write replacing the earlier one.

# Recursion on trees: return a value and combine

```python
def height(n: TreeNode | None) -> int:
    return 0 if n is None else 1 + max(height(n.left), height(n.right))

def is_same(p: TreeNode | None, q: TreeNode | None) -> bool:
    if p is None or q is None:
        return p is q
    return p.val == q.val and is_same(p.left, q.left) and is_same(p.right, q.right)

# balanced: return height, or -1 if unbalanced (single O(n) pass)
def check(n: TreeNode | None) -> int:
    if n is None:
        return 0
    l = check(n.left)
    if l == -1:
        return -1
    r = check(n.right)
    if r == -1 or abs(l - r) > 1:
        return -1
    return 1 + max(l, r)
```

**Diameter** (longest path, in edges): at each node `left + right` heights; track the global max while returning the height.

```python
best = 0

def h(n: TreeNode | None) -> int:
    global best                       # or use nonlocal inside a function
    if n is None:
        return 0
    l, r = h(n.left), h(n.right)
    best = max(best, l + r)
    return 1 + max(l, r)
```

**Maximum path sum** (any node to any node): return the best **downward** path (`node + max(0, best child)`), but update the global answer with `node + max(0,left) + max(0,right)`.

Pattern: _return one thing to the parent, record another globally._ All O(n).

# Logging with correlation

Logs from many machines are only useful if you can **tie them together**.

- Use **structured logs** (key=value / JSON) through the `logging` module, not free text.
- Every line carries: **timestamp, level, node/service, a request or trace id** (correlation id), and domain fields (term, logical clock, key).
- Generate the id at the edge; **propagate it** through calls (headers, a `contextvars.ContextVar`) and include it in every log line and error.
- Log at **boundaries** (request in/out, state changes), not in tight loops; never log secrets.

```python
import contextvars, json, logging

request_id = contextvars.ContextVar("request_id", default="-")

class JsonFormatter(logging.Formatter):
    def format(self, record: logging.LogRecord) -> str:
        return json.dumps({
            "ts": self.formatTime(record), "level": record.levelname, "node": NODE_ID,
            "req": request_id.get(), "msg": record.getMessage(), **getattr(record, "fields", {}),
        })

log = logging.getLogger("kv")
log.info("append", extra={"fields": {"lc": clock.tick(), "key": k}})
```

Then `grep req=abc123` across all nodes reconstructs one request's path; sort by logical clock to see causal order.

1. **Wall-clock ordering.** Clocks on different machines drift and are synchronized only approximately (and can jump backwards), so timestamps don't reflect real or causal order. Use logical/vector clocks for causality.
