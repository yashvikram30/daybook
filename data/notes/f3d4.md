# Regular expressions: patterns for text

A **regular expression** (regex) describes a set of strings, and the `re` module finds and edits text that matches. Use a **raw string** (`r"..."`) so Python leaves the backslashes alone.

```python
import re

text = "Contact ada@example.com or lin@test.org by 2025-06-30."
re.search(r"\d{4}-\d{2}-\d{2}", text).group()          # '2025-06-30'
re.findall(r"[\w.]+@[\w.]+\w", text)                    # ['ada@example.com', 'lin@test.org']
re.sub(r"\s+", " ", "a   lot    of   space")             # 'a lot of space'
```

Key functions: `re.search` (first match anywhere, returns a match or `None`), `re.match` (match at the start only), `re.findall` (all matches as a list), `re.sub(pattern, replacement, text)` (replace) and `re.split`.

| Pattern                    | Matches                                                               |
| -------------------------- | --------------------------------------------------------------------- |
| `.`                        | any one character (except newline)                                    |
| `\d`, `\w`, `\s`           | a digit, a word character, whitespace (capital letter = the opposite) |
| `[abc]`, `[a-z]`, `[^0-9]` | one of those, a range, anything but                                   |
| `*`, `+`, `?`              | zero or more, one or more, zero or one                                |
| `{3}`, `{2,4}`             | exactly 3, between 2 and 4                                            |
| `^`, `$`                   | start, end of the text                                                |
| `( )`                      | a group: capture part of the match                                    |
| `a\|b`                     | a or b                                                                |

Groups let you pull parts out: `m = re.search(r"(\w+)@(\w+)\.com", s)` then `m.group(1)` is the user name. Quantifiers are **greedy** (match as much as possible); add `?` (`.+?`) to make them match as little as possible. Test patterns live on regex101 before putting them in code. Write simple patterns, check them on several inputs including ones that should _not_ match, and prefer ordinary string methods (`startswith`, `split`) when they are enough.

# Running things from Python

The standard library also lets a script work with the machine:

```python
import os, shutil, subprocess

os.listdir(".")                       # names in a folder
os.path.exists("notes.txt")
shutil.copy("a.txt", "b.txt")
result = subprocess.run(["ls", "-l"], capture_output=True, text=True)
print(result.returncode, result.stdout)
```

`subprocess.run` starts another program and returns its exit code and output. Pass the command as a **list** of words, not a single string, so spaces and quotes in file names cannot be misread as extra commands. `sys.argv` carries the command-line arguments, which is how a script takes input without asking: `python3 extract.py input.txt`.
